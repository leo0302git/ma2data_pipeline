review requests targeted dynamic controls, preserve the package's scoring semantics and return

Write only corrected authored files. Return `result_json` with a nonempty `summary` and `fixed_checks` listing the addressed confirmed check IDs. Use `needs_review` if the defect cannot be repaired within the frozen task.
